# LanPulse 1.34.1

## Backup storage fix
- Fixes the default backup directory access for the hardened systemd service.
- Creates the default backup directory with private permissions during installation.
- Adds configurable backup storage through the `LANPULSE_BACKUP_DIR` environment variable.
- Displays the active backup location in Settings.
- Documents custom writable paths for direct installations and persistent writable volume mounts for container deployments.

## Compatibility and safety
- Keeps the existing backup archive format, verification, and restore workflow.
- Does not change the dashboard layout or add automatic backup scheduling.
- Includes tests for configured backup paths and rejects relative backup directory settings.

## Tests
- The release is published only after the main-branch pipeline succeeds.
