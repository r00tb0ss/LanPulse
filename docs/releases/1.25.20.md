# LanPulse 1.25.20

## Fix: OpenVAS results attached to the wrong machine
OpenVAS scans are requested by IP address, and addresses get reused (DHCP, or swapping a VM for another). Results could end up on whichever device held the address afterwards, for example a Metasploitable VM's findings showing on a Windows Server that took over its IP.

- Findings are now tied to the machine's MAC address and only shown on that machine.
- Older results with no record of which machine was scanned are hidden when the scan finished before the device first appeared.
- The weekly automatic scan no longer treats a new machine on a reused IP as "already scanned".

If a device still shows findings from the wrong machine, run a fresh OpenVAS scan on it; that replaces the old results.

## Upgrade
Settings > Update > Check for updates. No `install.sh --upgrade` needed.
