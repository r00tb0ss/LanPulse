# LanPulse 1.34.15

## Honeypot fixes
- Restores the captured-file links inside an opened attack session; they stopped responding after the workspace redesign.
- Keyboard activation of the Overview metric cards now applies the same filter as a mouse click, and opening Activity from an unfiltered card clears any earlier filter.
- Campaign correlation ignores widely shared public resolvers and common domains, and requires three shared behavior tags before reporting a behavior pattern, so fewer unrelated sources are grouped together.
- SSH key indicators now use the standard OpenSSH SHA256 fingerprint format, so they can be matched against other tools.

## Performance
- Attacker profiles and campaign correlation are cached for 30 seconds, so reopening the Honeypot view no longer recomputes them each time.
- File entropy is calculated with a faster routine; results are unchanged.

## Tests
- The merge-request pipeline runs Python compilation, JavaScript syntax checks, asset-reference validation, and the unit test suite.
