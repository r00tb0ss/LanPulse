# LanPulse 1.25.8

## Topology
- The Spread view now spaces devices out much more by default: more room between a switch or access point and its devices, between neighbouring groups, and between individual devices, so the map no longer looks clustered.
- Drag positions you saved are kept as before; use Reset to return to the new default layout.

## Upgrade
Settings > Update > Check for updates. No `install.sh --upgrade` needed.
