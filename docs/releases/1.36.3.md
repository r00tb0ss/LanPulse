# LanPulse 1.36.3

## YARA inside Honeypot
- Moves YARA Scanner into the Honeypot section as a dedicated YARA subsection, removing the standalone top-level navigation item.
- Makes each captured-file result expandable so operators can inspect its SHA-256, file type, size, honeypot score, scan coverage, and any matching YARA rules, tags, and descriptions.
- Keeps captured artifacts available in their existing Honeypot section.

## Safety
- YARA continues to analyze captured files as data only. LanPulse does not execute captured samples.
