# LanPulse 1.25.32

## Threat map: names for more countries
The map only labelled the 10 to 12 busiest countries. It now labels every country with activity, busiest first, skipping any name that would sit on top of one already shown. In crowded places such as Europe, the rest appear as you zoom in, and hovering any country still shows its name.

## Upgrade
Settings > Update > Check for updates. No `install.sh --upgrade` needed.
