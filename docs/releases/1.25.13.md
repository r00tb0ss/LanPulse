# LanPulse 1.25.13

Security and robustness fixes found in a review of the recent topology, UniFi and honeypot work.

## Fixes
- **Honeypot connection limits:** at most 300 open decoy connections at once and 8 per address, so one scanner can't use up every socket.
- **Honeypot disk use:** stored hits per address are now capped per time window. Before, the flood limit only stopped alerts, so a scanner hammering a decoy could fill the database. The setting is now labelled "Alert and map at most".
- **Honeypot sensor key:** compared in constant time.
- **Topology zones:** zone colours are validated (they were passed straight into the page), and bad requests return an error instead of crashing.
- **Topology CSV export:** device names that start with `=`, `+`, `-` or `@` can no longer run as spreadsheet formulas when opened in Excel or Sheets.
- **UniFi settings:** the gateway address and site name are validated (no paths, `@` or spaces), and redirects are never followed, so the API key can't be sent to another host.

## Upgrade
Settings > Update > Check for updates. No `install.sh --upgrade` needed.
