# 1.38.3

Accuracy pass on honeypot campaign correlation, so that only real shared evidence links attackers together.

- IP-lookup services (ifconfig.me, icanhazip.com, ipify, ipinfo and similar), common code hosts and package sites, and any subdomain of a listed site no longer link unrelated sources.
- A shared mix of only generic bot steps (recon, download, chmod, run, delete) is no longer reported as a behavior pattern; it needs at least one distinctive step.
- An SSH client fingerprint shared by 10 or more sources is rated low confidence, because it identifies a common SSH library rather than one operator.
- Real shared payload hosts, SHA-256 hashes and SSH keys still link as before.

Correlations remain evidence links, not attribution.
