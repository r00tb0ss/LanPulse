# LanPulse 1.36.9

## Threat dashboard visual refresh
- Introduces a clearer command-center visual hierarchy for the Threats dashboard.
- Strengthens visual grouping and layout for threat metrics, the live attack map, live feed, local alerts, and analytics.
- Preserves the existing live attack map and its expandable viewing experience.

This release focuses on the Threats dashboard presentation. It does not change the underlying scanning or threat-detection engines.
