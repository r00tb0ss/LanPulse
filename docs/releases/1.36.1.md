# LanPulse 1.36.1

## Automated YARA malware matching
- Installs the `yara-python` engine with LanPulse and automatically provisions the curated YARA Forge Core rule package.
- Verifies the official GitHub release asset's published SHA-256 digest and archive size before extracting rules.
- Validates the complete rule package before atomically activating it. A failed update leaves the last working managed package in place.
- Checks for rule updates weekly using a persistent systemd timer. The updater runs independently of the dashboard.
- Keeps owner-provided rules outside the managed package so weekly updates never overwrite custom rules.
- The Honeypot > captured files view reports YARA engine status, managed/custom rule counts, package version and update errors.
- Captured files remain static bytes only; YARA rules are compiled with includes disabled, scan timeouts and bounded rule/package sizes.

## Notes
YARA matches are investigative indicators, not proof that a file is malicious. YARA Forge Core is curated but can still produce false positives.
