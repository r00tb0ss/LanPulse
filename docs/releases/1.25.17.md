# LanPulse 1.25.17

## Metasploit badges on OpenVAS findings
When OpenVAS and LanPulse's built-in checks reported the same classic hole (for example DistCC or Ghostcat), the OpenVAS entry won and lost its Metasploit module, so the badge and the copy-ready commands in Red Team were missing. The module is now carried over.

Also fixed: the built-in checks' Metasploit modules were stored in a shape the page read as a single letter. They now show the full module name.

## Fix: "Find a device" covered the Topology buttons
On a PC screen the search box floated over the Topology toolbar. The toolbar now sits below it.

## Upgrade
Settings > Update > Check for updates. No `install.sh --upgrade` needed.
