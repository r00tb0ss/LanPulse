# LanPulse 1.25.30

## Vulnerabilities: no more "NVD returned HTTP 404 for windows_server_2008"
NVD answers 404 when it doesn't recognise the exact product name LanPulse asks for, and Windows Server 2008 was hitting that. LanPulse now retries with the other spellings NVD accepts, and if NVD truly has nothing under that name it moves on quietly (logged for troubleshooting) instead of showing an error and pausing 30 seconds. Rate-limit (403/429) and other errors behave as before.

If a product still returns nothing, the OpenVAS scan remains the way to see that host's flaws.

## Upgrade
Settings > Update > Check for updates. No `install.sh --upgrade` needed.
