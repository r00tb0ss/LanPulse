
## Scan results
When more than one thorough scan finished at the same moment, the vulners.com findings of one device could be attached to another. Each scan now keeps its own results.

## Network sweep
When the sweep had to fall back to nmap and nmap returned something unreadable, the sweep failed with an unpacking error instead of just finding nothing. It now returns an empty result.

## Upgrade
Settings > Update, or `git pull origin main && sudo ./install.sh`.
