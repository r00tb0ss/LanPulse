# LanPulse 1.34.11

## Honeypot malware analysis
- Adds evidence-backed static behavior findings for captured shell-script samples, with source-line evidence for observed command-and-control, SSH scanning and propagation, embedded credentials, persistence attempts, account changes, SSH-key artifacts, and remote command execution.
- Extracts structured indicators including IRC servers and channels, referenced ports, and embedded SSH credentials.
- Corrects overbroad classifications: an IRC TCP socket alone is not proof of a conventional reverse shell, and commands that terminate or remove miner processes are not proof that the sample performs cryptocurrency mining.
- Displays behavior findings and extracted indicators in the malware detail view.

## Honeypot workflow and presentation
- Separates Honeypot into Overview and Analysis subtabs, keeping decoy activity and attacker/service investigation in Overview while grouping captured sessions, sensors, file/hash intelligence, and SSH fingerprints in Analysis.
- Improves the visual hierarchy, card and detail layouts, evidence readability, theme-aware surfaces, responsive behavior, and keyboard focus visibility across Honeypot Overview and Analysis.

## Compatibility and safety
- Captured samples remain subject to static inspection only; sample bytes are not executed or interpreted.
- Uses existing honeypot event, session, sensor, and hash-addressed sample data.
- Does not change honeypot listeners, sensor ingestion, captured-sample storage, APIs, data retention, installer, updater, rollback, service configuration, or persistent data behavior.
