# LanPulse 1.34.12

## Honeypot investigation and intelligence
- Adds score-band filtering to captured sessions and malware samples, making large investigation lists easier to narrow down.
- Adds source-IP attacker profiles and source-specific session history for investigating repeat activity.
- Reconstructs evidence-backed attack timelines and correlates related activity into campaigns using observed indicators and confidence levels.
- Expands static malware behavior analysis with source-line evidence and structured indicators.
- Reorganizes Honeypot into a focused intelligence workspace with dedicated investigation areas, preserving existing investigation workflows and shared data sources.

## Backup safety
- Requires an authenticated dashboard session before creating a backup.
- Prevents concurrent backup jobs from running against the same backup workflow.
- Writes the backup manifest with a proper trailing newline.

## Compatibility and safety
- Captured samples remain subject to static analysis only; sample bytes are never executed.
- Campaign correlation and attacker profiles describe observed evidence, not confirmed operator identity or attribution.
- The Honeypot workspace redesign reuses existing investigation data and does not change decoy listener behavior or sensor operation.

## Tests
- The merged Honeypot workspace change passed its merge-request pipeline.
- The main-branch pipeline for the merged release contents passed, including Python compilation, JavaScript syntax checks, asset-reference validation, and the unit test suite.
- The release pipeline publishes the `lanpulse.zip` updater asset and verifies the published release after this version change is merged.
