# LanPulse 1.34.2

## Backup reliability
- Fixes manual backups failing when OpenVAS is running by excluding its transient gvmd PID file and Unix socket.
- Keeps persistent OpenVAS configuration and data in backups.
- Does not change OpenVAS ownership, file permissions, or LanPulse systemd security restrictions.

## Tests
- Adds regression coverage confirming the runtime PID file and socket are skipped while persistent scanner configuration is retained.
- Includes the full existing test suite.
- The release is published only after the main-branch pipeline succeeds.
