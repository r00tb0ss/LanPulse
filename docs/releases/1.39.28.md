# LanPulse 1.39.28

## AI investigations use one call when the evidence fits
- The local-model size check counted every byte as a token, about three times too pessimistic, so ordinary evidence was split into several slow chunked calls. It now uses a realistic estimate.
- Safety is kept: if Ollama reports that the prompt filled its context window, LanPulse discards that answer and automatically falls back to chunked analysis. Evidence is never silently cut.
- Investigations now log the evidence size, whether a single call or chunking was used, and how long it took, so slow runs can be diagnosed.
