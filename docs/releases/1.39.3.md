# 1.39.3

Settings > Backup: delete old backups and keep only the newest few.

- Each saved backup now has a **Delete** button (asks first; it cannot be undone).
- A new **Keep** setting: all backups (the default, nothing is ever deleted automatically) or only the newest 1, 3, 5, 10 or 20. Choosing a number deletes the older ones right away, and older ones are removed after each new backup.
- Only files with LanPulse's own backup file names are ever touched. Anything else in the backup folder, and anything that is not a plain file, is left alone.
- Like creating and downloading backups, deleting needs a dashboard login.

Update files are unchanged: LanPulse still keeps just one update zip (removed after a successful install) and one rollback archive.
