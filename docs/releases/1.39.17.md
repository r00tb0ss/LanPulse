# LanPulse 1.39.17

## Improved
- **C2 Intelligence loads more efficiently on repeat visits.** The server reuses the bounded analysis result for 30 seconds instead of rescanning the selected honeypot session and sample window each time the page is opened.
- Added a manual **Refresh** action to bypass the short-lived C2 cache and request fresh analysis.
- C2 indicator evidence is now collapsible so analysts can scan candidate indicators more quickly while retaining access to the underlying evidence and session/sample links.
- Sandbox runtime sensor controls are loaded only when the sensor section is opened, reducing unnecessary work during the initial C2 page render.
- Refined C2 metric labels and singular/plural sample counts for clearer presentation on smaller screens.

## Accuracy and evidence
- The selected analysis window and evidence are preserved; caching changes when analysis is recomputed, not which evidence is included.
- Extracted indicators remain candidates, not proof of execution or command-and-control activity. Runtime observations remain distinct from extracted strings and do not by themselves prove C2.
