# LanPulse 1.35.0

## Read whole captured files
- A captured file's detail view has **View whole file** and **Hex view**. Scripts and text files open as text, everything else as a hex listing, a page at a time with **Load more**.
- The contents are shown as plain text only. Control, zero-width and text-direction characters are replaced with a visible mark so nothing is hidden from the reader.
- The view also shows where the file is stored on the LanPulse machine, for copying it to an analysis machine.
- Captured files are still never run and never offered for download.

## Keep more of what attackers send
- Captured files up to 20 MB are stored (was 5 MB).
- Up to 2,000 files or 1 GB are kept before the least recently seen are removed (was 500 files or 300 MB). Backups grow with the stored files.
- Commands are kept up to 8,000 characters each (was 1,000), so a script pasted or echoed into the shell is kept. A session keeps about 300,000 characters of commands in total.

## Sensors
- Existing sensors keep the old 5 MB and 1,000-character limits until their installer is run again from Honeypot > Sensors > Add sensor.
- The "largest file to keep" sensor option now goes up to 20 MB.

## Tests
- Adds coverage for paging a whole script, hex listings, inert text, removed files, bad names and long commands on the server and the sensor forwarder.
