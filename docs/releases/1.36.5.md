# LanPulse 1.36.5

## Honeypot file investigation
- Adds a clear static-analysis triage summary separating YARA matches, suspicious indicators, behavioral findings, and the absence of reported detections. These signals are explicitly not presented as proof that a sample is malicious or harmless.
- Makes extracted URLs, IP addresses, and domains easier to read in the detail panel while keeping them inert and non-clickable.
- Preserves defanged indicator values for safe copying and adds a JSON IOC report export.
- Adds optional VirusTotal indicator lookups; these send the selected indicator to VirusTotal and open the search result in a separate tab.
- Keeps captured files as data only: LanPulse never executes samples.

## YARA
- Retains rule names, tags, descriptions, and match counts in the captured-file detail view.
- Shows architecture and behavioral findings when static analysis has enough information to report them.
