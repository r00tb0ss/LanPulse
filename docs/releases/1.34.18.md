# LanPulse 1.34.18

## Update log
- Each dashboard update now starts with a fresh log. Previously the log from the last update stayed on screen while the checksum was verified and the rollback archive was built, so the first lines shown belonged to an earlier run.
- The log now shows the update's start time, the checksum check and the rollback-archive step as they happen.
- The updater script is replaced during an update, so the cleaner log appears from the update after this one.

## Install instructions
- The README and website now include `chmod +x install.sh` before `sudo ./install.sh`.
- `install.sh` is marked executable in the repository, so new release zips carry the permission.

## Tests
- Adds coverage that the update log is reset once, before the checksum check, and only appended to afterwards.
- The merge-request pipeline runs Python compilation, JavaScript syntax checks, asset-reference validation, and the unit test suite.
