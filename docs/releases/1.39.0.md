# 1.39.0

The IP info box (opened from the live feed, the map, the Network tab or the Honeypot tab) now answers four questions it could not before.

- **Targeted or background noise?** Each attacking IP gets a plain read (research scanner, mass scanning, sweeping for one service, persistent, reached a real service, one-off probe, decoy-only attacker, or no clear pattern) with the evidence behind it and a confidence level. It is a pattern in the traffic, not proof of intent, and the box says so.
- **Did your network talk to it?** Lists which of your devices connected out to that address in the last 7 days, on which ports, and when, with a warning when any did. Click a device to open it.
- **Everything we know about it.** Honeypot sessions, whether it logged in, SSH client fingerprints, captured files, campaign links to other attacking IPs, and other addresses in the same /24 that also attacked.
- **Attack sequence.** The newest honeypot session that did something, shown as an ordered timeline.

Each part is optional: if a source has nothing, its section is simply not shown. No existing score, detection or data changed.

Limits: the outbound check only sees traffic that passes through your router, and the behaviour read is a heuristic.
