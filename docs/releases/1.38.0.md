# LanPulse 1.38.0

## DNS
- **AdGuard Home** is now a supported DNS source alongside Pi-hole. On the DNS tab, choose the source, then enter the address, username (AdGuard Home) and password.
- LanPulse reads AdGuard Home's query log the same way it reads Pi-hole's: lookups and blocks over time, top and blocked domains, per-device lookups, and an alert when a device looks up a known malware domain.
- Switching source or address forgets the saved password until you enter it again, so a stored password is never sent somewhere new.
- The DNS page and test result name the source in use.
