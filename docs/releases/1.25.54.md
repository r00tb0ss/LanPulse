
## Reset web server
`app.py --reset-web` failed with a FileNotFoundError when the data folder did not exist yet (for example a fresh `--data-dir` for a demo). It now creates the folder.

## Settings file
The first-run import of command-line options and `--reset-web` wrote the settings file before restricting who can read it. It is now created private from the start.

## Account and map layout
Changing the dashboard password no longer holds up the rest of LanPulse while the password is hashed. A malformed map layout request now gets a clear error instead of a server error.

## Upgrade
Settings > Update, or `git pull origin main && sudo ./install.sh`.
