# 1.31.0

## Health board
- The Services tab now opens with a **LanPulse health** card. It shows whether each part LanPulse relies on is alive and when it last reported: firewall logs, UniFi, SNMP, Pi-hole DNS, vulnerability data and every honeypot sensor.
- Each part gets a status (Working, Check or Problem) and a plain explanation, for example "Silent for 2.0 hours" for a sensor that stopped reporting, with a hint on what to look at. A part you have not set up is listed quietly as "Not set up", not as an error.
- The Services tab badge also turns on when something needs attention, so a dead sensor no longer goes unnoticed.
- Nothing new is collected. The board reads the status each part already keeps.
