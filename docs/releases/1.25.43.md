# LanPulse 1.25.43

## Shared switch ports no longer show the same speed on every device
Several machines plugged into one switch port, such as virtual machines on one host, were each shown the whole port's traffic as if it were their own, so they all displayed the same download and upload. A shared port's total is no longer given to any one device. A device shows its own speed when UniFi reports one for it and none otherwise, and its details now say when it shares a port with other devices.

## Upgrade
Settings > Update > Check for updates > Download > Install. Your devices, history, settings and login are kept.
