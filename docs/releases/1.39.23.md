# LanPulse 1.39.23

## Authorized public IP scanning
- Adds a separate workflow for manually entered public IPv4 scan targets.
- Requires dashboard authentication, an explicit authorization attestation, and a final confirmation before an active scan starts.
- Supports bounded Nmap TCP discovery with light service detection and Greenbone/OpenVAS Full and Fast profiles.
- Rejects private, loopback, link-local, multicast, reserved, invalid, and IPv6 targets.
- Prevents concurrent public scans, persists scan history, and marks interrupted work after a restart.
- Public attacker IPs are never selected or scanned automatically. Only scan systems you own or have explicit permission to assess.

## AI security investigation
- Gives the AI analyst access to all retained honeypot evidence, including attempted credentials, raw event details, Cowrie sessions and commands, captured sample analysis, YARA matches, and runtime telemetry.
- Adds stored authorized public-scan findings to AI threat investigations so results can be correlated with observed threat activity.
- Preserves the distinction between observed facts, AI assessment, and unknowns; a scan finding or honeypot interaction is not automatically proof of compromise.
- Makes oversized evidence requests fail explicitly rather than silently dropping evidence.

## Validation
- Adds regression coverage for public-target validation, scan persistence and restart recovery, and AI access to authorized scan results and retained evidence.
- Python, shell, JavaScript, unit-test, and browser-view CI checks passed on the implementation commit. The release commit will run the full CI suite again before automatic publication.
