# LanPulse 1.36.4

## YARA setup and management
- Adds a dedicated YARA tab under Settings for engine and managed-rule health.
- Adds authenticated install/repair, manual YARA Forge Core rule updates, and weekly update scheduling controls.
- Uses a restricted root-owned helper and systemd path watcher; the dashboard can request only allow-listed YARA actions and never executes package-manager or root commands directly.
- Keeps the default installer behavior: install yara-python, fetch and validate the managed YARA Forge Core rules, and enable weekly rule updates.
- Preserves custom YARA rules and the last known-good managed rules when an update fails.
- Displays rule package version, loaded files, rule counts, update timestamps, errors, and task logs.

## Safety
- YARA continues to scan captured files as data only; LanPulse never executes captured samples.
- Management actions require dashboard authentication.
