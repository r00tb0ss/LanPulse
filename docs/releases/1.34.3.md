# LanPulse 1.34.3

## Update and rollback safety
- Expands the updater rollback archive to cover the Python virtual environment and systemd configuration needed to restore the previous installation.
- Verifies the rollback archive contents before an update proceeds.
- Reloads systemd after restoring service configuration.
- Verifies restored files and confirms the LanPulse service is active before reporting rollback success.
- Preserves `/opt/lanpulse/data` during updater rollback.

## Installer and service reliability
- Preserves systemd hardening when LanPulse fails to start during installation or upgrade; reports journal instructions instead of silently disabling hardening.
- Ensures the Raspberry Pi Cowrie service includes its virtual-environment binaries in PATH, allowing systemd to locate `twistd`.
- Leaves the container sensor installer unchanged.

## Tests
- Adds regression coverage for rollback archive coverage and restoration verification.
- Adds coverage ensuring installer startup failures do not disable systemd hardening.
- Adds coverage for the Raspberry Pi Cowrie service PATH.
- The release is published only after the main-branch pipeline succeeds.
