# LanPulse 1.25.58

A code-review release.

## Fixed
- **Operations Center (wall display):** the compromised-device banner could show a green "No compromised devices" even though it had never checked. It depended on data that only loads after the Threats tab's traffic layer has been opened. It now fetches the last 24 hours of connection data itself, and shows "Checking for compromised devices…" until that data arrives.
- **AI analyst:** the model name hint for Anthropic in the setup form now matches the default the server uses (`claude-sonnet-5-5`).

## Reviewed
- Every front-end script and `install.sh`, `signatures.py` and the rest of `alerts.py` were read through for bugs. Nothing else needed changing.
