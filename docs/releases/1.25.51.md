
## DNS page
The DNS page read the device list and the recent-lookups list while the poller was changing them, which could now and then cause a server error. It now works from a copy.

## Device identification
A device that answers the UPnP discovery with a crafted description (one built to blow up in memory when parsed) is now ignored instead of parsed.

## Upgrade
Settings > Update, or `git pull origin main && sudo ./install.sh`.
