# LanPulse 1.25.18

## Fix: Topology Traffic view stopped moving
Live speeds from UniFi are now used only when several devices report one. If UniFi reports speed for just one or two devices, the map goes back to the connection-based view so the cables keep animating.

Also: the map no longer redraws itself when nothing changed, which could restart the cable animation on every background refresh.

## Upgrade
Settings > Update > Check for updates. No `install.sh --upgrade` needed.
