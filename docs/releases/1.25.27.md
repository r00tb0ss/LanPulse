# LanPulse 1.25.27

## Automatic checks on every change
Every pull request and push to main now runs a quick check on GitHub: Python and JavaScript syntax, a small set of tests for logic that has broken before (Metasploit lookups, OpenVAS host filtering, honeypot parsing, bandwidth rates), that the web page only references script and style files that exist, and that release notes exist for the version. Nothing changes in the app itself.

## Upgrade
Settings > Update > Check for updates. No `install.sh --upgrade` needed.
