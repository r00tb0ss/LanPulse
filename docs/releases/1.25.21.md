# LanPulse 1.25.21

## OpenVAS knows when two devices share an IP
If more than one device answers for the same address (two VMs both set to the same static IP, for example), a scan of that address could land on either one and the findings would be mixed up.

- Every network sweep now checks for addresses answered by more than one device and raises an **IP address conflict** alert naming the devices.
- OpenVAS refuses to start a scan on a conflicting address and says why.
- If a conflict shows up while a scan is running, the results are not saved, with an explanation, instead of landing on the wrong machine.

The router's address is still handled by the existing router-impersonation check.

## Upgrade
Settings > Update > Check for updates. No `install.sh --upgrade` needed.
