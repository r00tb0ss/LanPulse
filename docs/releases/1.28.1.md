# LanPulse 1.28.1

## Fixes for the FTP and web decoys

- A client that sends request headers one byte at a time could keep a decoy connection open for many minutes. Web
  connections are now cut after 90 seconds and FTP connections after 5 minutes, whatever the client does.
- On a Raspberry Pi the decoy service is only allowed to write inside Cowrie's `var` folder, and systemd would refuse to
  start it if that folder did not exist yet. The installer now creates it first.
