# LanPulse 1.25.0

## New: Topology view (Network tab)
- Internet > gateway > switches > access points > devices, grouped by what each connects to.
- Wi-Fi details: AP model, radios, SSIDs, client counts; per-client signal, band, channel, link speed. Switch ports up and PoE.
- VLAN/zone grouping, color-by modes, focus path to the internet, collapsible clusters, minimap.
- Changes feed (joined, left, moved, roamed), traffic shading, export to SVG/PNG/draw.io/CSV.
- Works with UniFi (read-only, automatic) and any other router (set connections by hand, add zones by CIDR).

## Notes
- UniFi parsing is not yet verified on a real UDM Pro; errors show in the Topology top bar.
- No SNMP/LLDP auto-discovery yet. PNG export omits icons.

## Upgrade
Settings > Update > upload lanpulse.zip. No `install.sh --upgrade` needed.
