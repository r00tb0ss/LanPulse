# LanPulse 1.38.1

## Vulnerability matching accuracy
- Version comparison now handles OpenSSL-style patch letters correctly. `1.0.1a` and `1.0.1b` used to count as older than `1.0.1`, which could hide flaws that affect those releases (Heartbleed, for one).
- `1.0` and `1.0.0` are now treated as the same version, and `1.0` correctly counts as newer than `1.0.0-rc1`.
- Banners such as `OpenSSH_8.2p1` and `Apache/2.4.41` are now read, and Debian package revisions such as `9.18.12-1~deb12u1` are reduced to the upstream version.
- Software with a similar name is no longer mistaken for something else: phpMyAdmin is not PHP, MySQL Router is not MySQL, and Squid Cache Manager, RediSearch and Eximon are no longer matched to Squid, Redis and Exim.
- A labelled set of 100+ real-world cases now checks all of this on every change.
