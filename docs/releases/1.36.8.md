# LanPulse 1.36.8

## Threat dashboard and live attack map
- Adds an expandable attack-map layout with controls for a larger and full-screen view.
- Groups repeated live threat events while retaining the underlying event details for investigation.
- Improves the presentation and styling of grouped inside-network security activity.
- Clarifies attacker investigations that are specific to honeypot evidence.

## Responsive dashboard
- Improves responsive layouts across dashboard views.
- Refines mobile threat-dashboard navigation and topology controls.
- Documents the responsive dashboard and mobile attack-map experience.

## Documentation and presentation
- Updates the project website and README to describe the responsive dashboard and grouped threat investigations.
- Restores the original LanPulse screenshots and theme gallery.
- Removes inaccurate dashboard mockups and corrects SVG theme-preview colors.
- Expands documentation for YARA scan details; malware samples continue to be scanned statically and are never executed.

This release focuses on dashboard usability, threat investigation, responsive layouts, and documentation. It does not introduce new AI malware-analysis claims or change the underlying vulnerability-scanning engine.
