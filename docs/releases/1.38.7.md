# 1.38.7

Faster page loads.

- Pages, scripts, styles and data are now compressed when sent (roughly five times smaller), which helps most over Wi-Fi, VPN or a phone.
- LanPulse's own scripts and styles are stamped with the release number, so the browser now keeps them for a year instead of re-checking about 30 files on every load. A new release changes the stamp, so an update is still picked up straight away.
- Backup downloads are left alone, since they are already compressed.
- The browser check in CI now verifies compression and caching on every change.
