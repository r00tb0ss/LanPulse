# LanPulse 1.25.23

## Fix: OpenVAS scans could return another machine's findings
A scan of one device (a Windows Server) could come back with the findings of a different one (a Metasploitable VM). OpenVAS may return results from other scans when LanPulse asks for a finished scan's results, and LanPulse trusted all of them.

OpenVAS tags every result with the host it found it on. LanPulse now keeps only results tagged with the address you scanned (results with no tag are kept) and does this before applying its result limit, so the right findings can't be pushed out. Dropped results are noted in LanPulse's log.

**What to do:** results already saved on a device by an earlier scan aren't changed. Run a fresh OpenVAS scan on that device and the wrong findings are replaced.

## Upgrade
Settings > Update > Check for updates. No `install.sh --upgrade` needed.
