# LanPulse 1.25.23

## OpenVAS results are checked against the address you scanned
OpenVAS tags every result with the host it found it on. LanPulse now compares that to the address you asked it to scan and drops results for any other host, so one machine's findings can't land on another. Dropped results are noted in LanPulse's log.

## Upgrade
Settings > Update > Check for updates. No `install.sh --upgrade` needed.
