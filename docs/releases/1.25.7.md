# LanPulse 1.25.7

## Topology
- Links now look like cables: a dark jacket with a lighter core for wired links, and dashed lines for Wi-Fi.
- With Traffic on, small packets travel along each cable toward the switch or access point. More connections means bigger, faster packets.
- Traffic uses its own colour scale, green when quiet through orange to red when busy, instead of the theme's teal. The bars and counts under each device use it too.
- Needs 1.25.6 (Spread view); included here.

## Upgrade
Settings > Update > Check for updates. No `install.sh --upgrade` needed.
