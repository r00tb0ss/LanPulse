# LanPulse 1.39.27

## Faster AI investigations without dropping evidence
- Repeated identical records (the same port, signature, target and sensor hit thousands of times) are merged into one record with a count, first/last time and every occurrence time (as compact gaps) before the AI reads them. Every distinct value, credential, command, URL and hash is still sent.
- A busy attacker that used to be split into dozens of sequential model calls now usually fits in one, so investigations finish in a fraction of the time. Only evidence that is still too large after merging repeats takes the chunked path.
- The evidence brief tells the model that repeats were merged and how much smaller it became.
