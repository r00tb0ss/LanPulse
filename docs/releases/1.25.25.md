# LanPulse 1.25.25

## See every vulnerability on every host
- **Device panel:** shows the six worst findings with a **Show all N** button that lists every one (and **Show fewer** to collapse).
- **Vulnerabilities tab:** an expanded service lists its first 40 findings with a **Show all** button, instead of cutting off with "+N more".
- **Limits raised:** LanPulse used to keep only 300 findings per device and show only the 40 worst services across your whole network, so busy hosts (a Metasploitable VM, an old Windows box) were cut off and some hosts were missing from the list. It now keeps up to 2,000 findings per device and lists up to 1,000 services; the config-issues list shows up to 500.

## Upgrade
Settings > Update > Check for updates. No `install.sh --upgrade` needed.
