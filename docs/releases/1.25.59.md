# LanPulse 1.25.59

## Fixed
- **Threats map:** country names are now drawn above the attack and traffic markers. Before, the map's own labels sat underneath them, so ripples and dots cut through the names (for example "Turkey", "United States" and "Singapore"). It was most visible with the **Both** layer turned on. The markers stay clickable through the labels.
- **Threats map:** dots no longer blink or stutter. Each refresh used to re-send the same dots, and every re-send restarted their ripple animation. Unchanged dots are now left alone. With both layers on, the soft glow around the dots is also turned off, which was slow to draw on phones.
