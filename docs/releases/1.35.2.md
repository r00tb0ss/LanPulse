# LanPulse 1.35.2

## Updates
- Check for updates now asks both GitLab and GitHub and offers whichever release is newer. Before, GitHub was only asked when GitLab could not be reached, so a release published only on GitHub was missed.
- When both have the same version, the GitLab copy is used as before. Every download is still checked against its published SHA-256 checksum.

## Tests
- Adds coverage for a newer release on GitHub, the same release on both, and either source being unreachable.
