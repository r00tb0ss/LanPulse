# LanPulse 1.39.21

## AI security investigation
- Adds an on-demand AI investigation to the Threat Map IP details panel.
- Uses LanPulse attack history, observed destinations and targets, honeypot session summaries, campaign links, cached reputation, and the cached Feodo C2 list.
- Clearly separates observed evidence from AI assessment and unknowns. Honeypot decoy activity is never treated as proof of compromise.
- Passive only: the agent does not scan, probe, block, or connect to the investigated IP.
- Attempted credentials and raw event details are excluded from the AI evidence brief.

## Threat Map performance
- Local IP context is briefly cached so the IP panel and AI investigation can reuse the same work.
- External reputation loading no longer repeats the expensive local honeypot, campaign, and outbound-flow context query.
- IP intelligence cache pressure now expires stale entries and evicts the oldest entries instead of clearing the entire cache.

## Validation
- Added regression tests for credential exclusion, decoy interpretation, and explicit C2-list matching.
- Full CI and browser checks run before the automatic release workflow publishes this version.
