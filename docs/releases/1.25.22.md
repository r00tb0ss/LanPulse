# LanPulse 1.25.22

## Metasploit badges for well-known CVEs
Findings with a famous Metasploit module (Ghostcat, DistCC, vsftpd backdoor, UnrealIRCd, Samba usermap, EternalBlue, MS08-067 and the like) now get the Metasploit badge and Red Team commands whichever scanner reported them, even when the Metasploit module list hasn't finished downloading or doesn't list that CVE. Findings with no CVE (for example Ingreslock or rlogin) still have no badge.

## Upgrade
Settings > Update > Check for updates. No `install.sh --upgrade` needed.
