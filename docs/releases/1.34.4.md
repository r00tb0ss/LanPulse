# LanPulse 1.34.4

## Cowrie timestamp accuracy
- Sets the Cowrie process timezone to UTC before startup for Raspberry Pi and container sensor installations.
- Ensures Cowrie event timestamps marked with `Z` are actually UTC, preventing a five-hour offset when the host uses Eastern time.
- Does not change the host machine's local timezone or LanPulse dashboard timezone display.

## Tests and release verification
- Adds regression coverage for UTC startup configuration in the Pi and container installers.
- Verifies after deployment that the expected GitLab release exists and includes the `lanpulse.zip` updater asset link.
- The release is published only after the main-branch pipeline succeeds.
