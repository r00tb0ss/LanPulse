# 1.38.2

Accuracy pass on device identification and malware/honeypot scoring. Each area was checked against labelled real-world cases, the wrong results were fixed, and the cases are now permanent tests.

## Device identification
- Printer, phone and access-point matching no longer fires on look-alike hostnames (for example `brotherton-pc`, `motorhead-pc`, `decorator-laptop`).
- Windows domain controllers and servers are no longer shown as desktops.
- ESXi hosts, Home Assistant, Mac mini/Studio, Amazon Fire tablets and Ubiquiti UNVR are recognised.
- A blank Intel network card is now "unknown" instead of a guessed laptop.
- A Canon camera is no longer called a printer.
- 70 labelled devices: 12 wrong before, 0 after.

## Malware and honeypot scoring
- Reading `authorized_keys`, `.bashrc` or `/etc/passwd` is no longer scored as planting a key, persistence or an account change.
- `bash -i` reverse shells are no longer also counted as running a dropped file.
- Downloads from localhost or 127.x (health checks) no longer score as downloads.
- A script that only plants an SSH key is no longer labelled an SSH worm.
- 71 labelled commands: 6 wrong before, 0 after. Labelled benign and malicious files are kept as tests.

Scores remain static triage indicators, not a malware verdict.
