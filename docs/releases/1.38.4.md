# 1.38.4

Accuracy pass on the dashboard security checks and the network security score.

- The default-login check no longer flags SFTP, or devices whose name merely contains "ilo" (for example "Milo" or "Pilot"). Real iLO, iDRAC, Grafana, FTP and Telnet services are still flagged.
- Plain HTTP on port 80 no longer lowers the security score. It is on almost every device and is only a risk if it serves a login, which a port number cannot show. It is still listed on the Red team view.
- Vulnerability matches on distro packages, which may already be patched by a backport, stay listed but no longer lower the score.

The score remains a prioritisation aid, not a certification.
