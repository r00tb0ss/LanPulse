# LanPulse 1.25.29

## Topology: links no longer blink on and off
UniFi reports each link's speed as a short snapshot, so two busy switches could take turns showing traffic, one going quiet while the other lit up. The map now holds each link's recent peak and lets it fade over a couple of refreshes, so a busy link stays lit. Display only; no data changes.

## Upgrade
Settings > Update > Check for updates. No `install.sh --upgrade` needed.
