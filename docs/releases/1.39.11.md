# LanPulse 1.39.11

## Changed
- Added **Settings > API Keys** as the central place for AbuseIPDB, abuse.ch, NVD, cloud AI and UniFi API credentials, with provider links, configured status, masked values and explicit key removal.
- Existing saved API keys are migrated automatically; the original service configuration fields remain synchronized for compatibility, so existing integrations continue working without re-entering credentials.
- Removed duplicate API-key fields from Threats, DNS, Vulnerabilities, AI Analyst and UniFi settings. Service-specific connection settings remain where they belong.
- Added independent key checks for AbuseIPDB, abuse.ch / MalwareBazaar and NVD. AI and UniFi credentials can still be tested from their respective setup screens.
- Clarified that AbuseIPDB and abuse.ch are separate providers and require different keys.
- Hardened abuse.ch authentication-key handling to prevent non-ASCII header characters from triggering `ordinal not in range(256)`.
