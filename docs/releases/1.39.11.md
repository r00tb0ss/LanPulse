# LanPulse 1.39.11

## Changed
- **Threat map colours now say who is who.** Attackers are red, suspicious sources (known internet scanners and probes) are yellow, and device data is blue. The map dots follow the same colours, and an attack that got through draws a slightly thicker line. The legend lists Attacker, Suspicious, Data and Your network instead of "Blocked at router" and "Reached a LAN device".

## Fixed
- **Honeypot session lists broke IP addresses across lines** on phones and tablets (for example `176.105.20` / `4.73`). An IP now stays on one line and the other details wrap beneath it.
