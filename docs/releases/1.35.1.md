# LanPulse 1.35.1

## Decode hidden content
- Scripts and typed commands are searched for content hidden by encoding: base64, base64 with gzip, and bytes written as `\x` escapes. What is found is decoded and shown, with its own tags and addresses, in the file and session views.
- A program echoed into a file in many small pieces is put back together and identified.
- One encoded layer inside another is followed once. Decoded content is treated as data and is never run.

## Inside Linux programs
- For captured Linux programs, the file view shows what the program's headers say: its loader, memory segments, the libraries it needs and the functions it imports, with plain-language hints about what those imports suggest.
- Flags a segment that is both writable and executable, and data appended after the end of the program.
- Both views are worked out when a file is opened, so they also cover files captured before this release.

## Tests
- Adds coverage for decoding, false matches, output limits, and reading intact and damaged program headers.
