# LanPulse 1.39.8

## Fixed
- **abuse.ch Auth-Key was rejected.** 1.39.7 stripped control characters from the key with a malformed pattern that also deleted digits, capital letters and several lowercase letters, so a saved or tested key no longer matched. Keys are now only trimmed of line breaks and control characters.
- **MalwareBazaar answers were forgotten** each time a sample was opened, causing repeat lookups. The cached answer now survives re-analysis.
- Report views of a sample no longer call MalwareBazaar; they show the cached answer only.

## After updating
Re-enter your abuse.ch Auth-Key in Settings > DNS (a key saved by 1.39.7 may already be damaged), then press "Test shared abuse.ch key".
