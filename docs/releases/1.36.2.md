# LanPulse 1.36.2

## YARA Scanner dashboard
- Adds a dedicated YARA tab showing engine availability, loaded rule files, managed rule count, Forge Core package/version/status, update timestamps, and reported loading errors.
- Lists captured honeypot files and any YARA matches reported for their details, including rule names and tags.
- Adds a refresh action and a shortcut to the Honeypot artifacts view.
- The dashboard reports the results of the existing captured-file analysis; it does not execute captured files or provide arbitrary file uploads.

## YARA rule handling
- Raises the managed YARA rule-file size limit to 8 MiB so the larger Forge Core ruleset can be loaded.
- Adds regression coverage for loading rule files larger than 2 MiB.

## Notes
- Managed YARA rules continue to be maintained by the LanPulse YARA updater. Custom rules remain server-managed in the YARA data directory.
