# LanPulse 1.39.9

## Fixed
- **abuse.ch Auth-Key still rejected in the honeypot MalwareBazaar lookup.** 1.39.8 fixed the key when saving it, but the lookup itself still cleaned the key with the same malformed pattern, deleting digits and many letters before sending it. The lookup now sends the key unchanged apart from trimming whitespace and control characters.
- **MalwareBazaar answers were forgotten** each time a sample was opened, causing repeat lookups. The cached answer now survives re-analysis.
- Report views of a sample no longer call MalwareBazaar; they show the cached answer only.

## After updating
Re-enter your abuse.ch Auth-Key in Settings > DNS if it was saved by 1.39.7, then press "Test shared abuse.ch key".
