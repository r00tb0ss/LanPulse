# LanPulse 1.27.0

## Customize a honeypot sensor

**Honeypot > Captured attacks and malware > Sensors > Add sensor** now has an optional **Customize** section. What you
choose is written into the one-line install command, so there are no extra steps on the Raspberry Pi, Linux box or
container.

- **Ports and services:** turn the SSH or Telnet decoy off, or pick other ports (1024 and up).
- **What the attacker sees:** the hostname, and a system (Debian 12, Debian 11 or Ubuntu 22.04) that the SSH banner and
  `uname` claim to be.
- **Which logins work:** every login, a login that works after a few failed tries, or only common default passwords.
- **Limits:** the biggest file to keep, memory and CPU caps for the honeypot, and (on a Pi or Linux install) how many
  days captures are kept and a disk limit that deletes the oldest captures first.

The values are checked in LanPulse and again by the installer, so only known settings with sensible ranges get through.
Run the command again with other settings to change a sensor later. A Pi install now cleans up with a systemd timer every
hour instead of a daily cron job, and it also removes old replay logs.

Nothing changes for sensors you already set up, and the built-in light honeypot is untouched.
