# LanPulse 1.34.0

## Manual backups

- Adds a Backup section under Settings.
- Create a backup on demand, view saved backups, refresh the list, and download an archive.
- Uses the existing local backup utility; backups are not scheduled automatically.
- Keeps restore as a documented manual command-line operation.

## Backup and restore safety

- Preserves directory permissions when restoring backups.
- Remains compatible with older format-version 1 backups.
- Verifies the backup archive and SHA-256 manifest before replacing data.
- Keeps the existing pre-restore data directory available for recovery.

## Update reliability

- Verifies the updater's rollback archive before installing an update.
- Stops before changing application files if the rollback archive cannot be created or verified.
- Fixes posture-history tracking so a failed database write can be retried.

## Website and CI

- Adds checks for local website and dashboard asset references.
- Updates the website and README with the backup feature.

## Tests

- Includes regression coverage for backup listing and safe archive access, restore behavior, updater rollback verification, posture-history retries, and website asset checks.
- The release is published only after the main-branch pipeline succeeds.
