# LanPulse 1.34.16

## Update integrity
- Release builds publish a SHA-256 checksum alongside `lanpulse.zip`.
- The in-app updater verifies downloaded release bytes against the checksum before staging them.
- The checksum is carried with the staged archive and checked again by the root-only updater immediately before extraction.
- Manually selected ZIPs are hashed when staged and checked again before installation; they are not treated as publisher-authenticated releases.

## Safety
- An update with a missing, malformed, or mismatched checksum is refused before installation.
- Existing rollback archive creation, verification, and automatic restore behavior remain in place.
- Terminal installation and recovery workflows remain available.

## Tests
- Covers release metadata parsing, matching and mismatched download checksums, missing checksum rejection, and root-updater verification ordering.
