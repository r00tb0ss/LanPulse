# LanPulse 1.25.16

## Real bandwidth in the Topology map
With UniFi connected, the **Traffic** view now shows live throughput per device (for example "4.2 Mbps") instead of connection counts.
- Cables, bars and the Spread view labels scale with how much data each device is moving, and switches and access points add up everything below them.
- The inspector shows **Throughput now** for a device, or **Throughput below** for infrastructure, plus connections in the last hour.
- A "Live throughput from UniFi" chip appears in the toolbar when rates are available.
- Without UniFi, it falls back to connection counts as before.
- UniFi is now polled every 30 seconds (was 60) so the numbers stay fresh.

Note: the rate is a snapshot taken about every 30 seconds, upload and download combined.

## Upgrade
Settings > Update > Check for updates. No `install.sh --upgrade` needed.
