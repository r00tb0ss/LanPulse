
## Alerts from background checks now reach you
Some alerts are raised away from the main loop: the "unusual traffic volume" check and hits reported by an outside honeypot sensor, such as an ESP32. They could fail without a trace, and your log showed a `coroutine 'to_thread' was never awaited` warning. Alerts now go out from any part of LanPulse, and the list that stops repeat alerts can no longer grow forever.

## Fewer rare errors
The flows summary, a device's history and the security score read data that the main loop was changing at the same moment. Now and then that produced a server error or a lost count. They now work from a copy.

## Map
A VM that UniFi reports as idle on a shared port no longer shows the port's traffic flowing on its cable. Its label already said idle. A wired device's overall rate now reads the same fields as its download and upload figures.

## Login
Checking a password no longer holds up the rest of LanPulse while it runs. A garbled login form or a threat-ingest key with unusual characters now gets a normal refusal instead of a server error. The login file is created private from the start.

## Upgrade
Settings > Update, or `git pull origin main && sudo ./install.sh`.
