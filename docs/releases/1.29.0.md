# 1.29.0

## The AI analyst now knows LanPulse

- The analyst is given a built-in guide to everything LanPulse is and covers (every tab, the honeypot and sensors, vulnerabilities, DNS, services, traffic, the Red Team report, alerts, updates), so "what can it do?" and "where do I find...?" questions are answered.
- It can now see live honeypot data: hits by service, the most tried usernames, passwords and pairs, top sources and countries, sensor status, recent sensor sessions and captured malware samples. It also sees DNS, services, device traffic, inside-LAN threats and vulnerability details.
- What it is shown depends on your question, so a honeypot question gets the full honeypot picture and a general question gets a short line about each area.
- With Ollama, LanPulse now asks for a larger context window so the guide and data are not silently cut off.
- New suggested questions about honeypot credentials and captured files.
- Text that comes off the network is shortened to one line and is still treated as untrusted.
