# LanPulse 1.25.60

## Fixed
- **Operations Center (wall display):** the attack map could stay blank. It was built once, a fraction of a second after the screen opened, and if the page hadn't finished laying out by then (or the world data needed its date-line fix-up, which only the Threats tab did) it never recovered. It now waits until it has a real size, applies the fix-up itself, and is retried on every refresh. If drawing still fails, the tile says so instead of staying empty.
