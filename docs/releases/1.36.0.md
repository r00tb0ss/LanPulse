# LanPulse 1.36.0

## Optional YARA rule matching
- If you put YARA rule files (`.yar` or `.yara`) in the `yara-rules` folder inside LanPulse's data folder and install the `yara-python` package, a captured file's detail view lists the rules it matches, with each rule's tags and description.
- Nothing changes until you do both. LanPulse does not download rules, does not ship any, and never takes a rule from a capture.
- Rule files are compiled one by one, so a mistake in one file does not hide the others. Rule `include` lines are switched off, each scan has a 10 second limit, and oversized or linked files are skipped.
- A match is evidence to check, not proof of what a file is. Captured files are only read as bytes and never run.
- To turn it on: run `/opt/lanpulse/venv/bin/pip install yara-python`, create `/opt/lanpulse/data/yara-rules` and put your rule files there, then restart LanPulse.

## Tests
- Adds coverage for missing package or rules, broken and oversized rule files, a failing scan, rule changes being picked up, and the file view.
