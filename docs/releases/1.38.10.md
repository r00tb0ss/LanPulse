# 1.38.10

Report polish: labels that read like words.

- Device types in reports now read "NAS", "Printer", "Raspberry Pi" and "Access point" instead of raw names like "nas" or "raspberrypi".
- Device status reads "Online" / "Offline", and the data-source table says "Working", "Needs attention", "Problem" or "Not set up" instead of "ok" and "off".

No change to any detection, score or data.
