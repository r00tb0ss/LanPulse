# LanPulse 1.25.37

## Updates now come from GitLab
**Settings > Update > Check for updates** now looks at the LanPulse releases on GitLab (gitlab.com/r00tb0ss/lanpulse) first and falls back to GitHub, using whichever has the newer version. Downloads are still limited to those release sites over HTTPS, and every update still goes through the same checks as a file you upload yourself. You can always choose a file manually instead.

## For maintainers
`tools/release_gitlab.py` publishes a release with `lanpulse.zip` attached (needs a GitLab token in `GITLAB_TOKEN`), and `.gitlab-ci.yml` runs the syntax and unit checks and publishes the project page.

## Upgrade
This one is installed by hand, once: Settings > Update > choose the `lanpulse.zip` you were given > Install. After that, updates come from GitLab.
