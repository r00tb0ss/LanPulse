# LanPulse 1.34.8

## Threats and Honeypot investigation improvements
- Reorganizes Threats analytics so traffic summaries, IPS detections, and top attackers are easier to scan.
- Keeps the live attack map, live feed, device traffic, inside-network events, hourly activity, countries, targeted services, and attacker details available.
- Groups honeypot credential intelligence while retaining credential pairs, most-guessed usernames, and passwords.
- Adds a dedicated Hash Intelligence area for captured-file hashes and SSH HASSH fingerprints.
- Retains captured-file SHA-256, SHA-1, MD5, static analysis, metadata, entropy, source information, related sessions, and VirusTotal lookup; adds hash-copy controls.
- Adds read-only HASSH summaries with first/last seen, session counts, source IPs, countries, SSH client software, services, and related-session navigation.
- Clarifies that HASSH fingerprints group SSH client handshakes and are not unique proof of identity or attribution.

## Compatibility and safety
- Uses existing stored honeypot session and sample data; does not add a new collection mechanism.
- Does not intentionally change detection, blocking, ingestion, sensor operation, installer, updater, rollback, service configuration, or persistent data behavior.
- Keeps existing Threats and Honeypot information and workflows available in the reorganized layout.

## Tests
- Includes the successful main-branch pipeline for the merged investigation layout.
- Includes regression coverage for HASSH aggregation and the existing unit and JavaScript syntax checks.
- The release is published only after the release-preparation pipeline and main-branch pipeline succeed.
