# 1.38.11

Vulnerabilities tab fixes for phones and tablets.

- On a phone, the "Fix these first" device cards no longer squeeze the device name into one letter per line; the tags now wrap underneath it.
- In "By device", each row now shows the name and finding count on one line, with the details and the OpenVAS scan and Attack view buttons on the line below, instead of the buttons crowding out the name and count.
- The count now says "findings" so it is clear what the number means.
- The browser check in CI now tests the phone layout so this cannot come back unnoticed.

No change to any detection, score or data.
