
## Settings file
The settings file (it holds your passwords and API keys) is now created private from the start. Before, it was briefly readable by other users on the server between being written and being locked down.

## Saves
A save started from a background task (such as an OpenVAS import) could be lost if the device list changed at that moment. It now tries again.

## Fewer rare errors
The vulnerability page and OpenVAS import read the device list while it was changing. They now work from a copy.

## Upgrade
Settings > Update, or `git pull origin main && sudo ./install.sh`.
