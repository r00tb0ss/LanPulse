# LanPulse 1.34.10

## Honeypot attack filtering and service investigation
- Adds evidence-based attack-type filters for credential attempts, protocol/request probes, and connection-only activity.
- Makes each service in Decoys Hit clickable to inspect the hosts that contacted that decoy.
- Adds service-specific host details, including source IP, hit counts, first/last seen, internal status, ports, credential-attempt counts, sensor, and available GeoIP/network information.
- Links hosts from the service detail view to the existing host investigation workflow.
- Keeps the categories focused on observed honeypot evidence; they do not claim confirmed attacker intent or attribution.

## Compatibility and safety
- Uses the existing honeypot event and sensor data; does not introduce a new collection mechanism.
- Does not change decoy protocol behavior, sensor port configuration, ingestion, retention, installer, updater, rollback, service configuration, or persistent data behavior.

## Tests
- Includes the successful main-branch pipeline for the honeypot attack filters and service host details in !98.
- The release-preparation pipeline must pass before merging.
- Publishing the release and updating any server are separate steps.
