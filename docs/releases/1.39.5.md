# 1.39.5

Light and Sand themes are readable everywhere.

- Green, amber and red notice boxes (YARA, Update, OpenVAS and others in Settings) had dark text on a dark background. They now use light tinted backgrounds with dark text.
- The Threats map toolbar, the Network layout buttons and the search bar over the map had faint text on the dark map. They are readable now.
- Severity badges, Red Team scores, Services health labels, DNS blocked counts, code blocks and "Blocked / Allowed" results were fixed the same way, along with the faint grey timestamps.
- The browser check in CI now switches to Light and Sand and fails if text is hard to read on any tab, any Settings page, the IP info box or the device panel. The default dark theme is unchanged.

No change to any detection, score or data.
