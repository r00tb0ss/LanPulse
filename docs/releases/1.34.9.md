# LanPulse 1.34.9

## Honeypot investigation list usability
- Shows the 10 most recent captured honeypot sessions by default, with a View all control for the remaining available results.
- Shows the 10 most recent captured-file malware entries by default, with a View all control for the remaining available results.
- Shows the 10 highest-ranked probing source IPs by default, with a View all control for the remaining available results.
- Expanded lists scroll inside their own bounded panels; Show less restores the compact view.
- Preserves existing ordering, session replay, hash details, copy controls, and underlying collection and analysis data.

## Compatibility and safety
- Limits the expanded session and captured-file requests to the existing API maximum of 500 records.
- No changes to data collection, detection, blocking, ingestion, retention, installer, updater, rollback, service configuration, or persistent data behavior.

## Tests
