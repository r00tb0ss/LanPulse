# LanPulse 1.33.1

## AI Attack Intelligence

- Adds a separate AI Attack Intelligence assessment to honeypot session details.
- Distinguishes automated, potentially AI-assisted, human-operated/inconclusive, and unknown activity.
- Shows an intelligence score, confidence, and the evidence behind the assessment.
- Uses conservative classification; ordinary automation is not labelled as AI activity without supporting indicators.
- Leaves the existing honeypot danger score and dashboard behavior unchanged.
- Requires no external AI service or database migration.

## Update package

- Publishes the official `lanpulse.zip` release package for the in-app updater.
- Publishes the updater feed for this version.

## Tests

- Main-branch CI must pass before the release is published.
- Includes tests for sparse sessions, repeated automation, staged attacks, and explicit AI-related indicators.
