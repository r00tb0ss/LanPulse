# LanPulse 1.36.11

## Malware analysis
- "Why this score?" now lists the static indicators that make up a sample's score. It was in the page before but never received data.
- Files over 4 MB are scanned with YARA the first time they are opened instead of during upload, so uploads are not held up.
- The VirusTotal "Investigate" button searches the readable indicator.

## YARA
- Rule loading is safe when several scans run at once, so a rule reload can no longer cause a scan to report no matches.
- Update staging and previous-package folders are no longer counted as owner rules.
- The setup helper no longer follows links in its working folder.
- Package dates show correctly when the status file stores them as numbers in text.

## Dashboard
- A group of grouped live-feed attempts you have opened stays open when new events arrive.
- The analyst's built-in help points to the GitHub repository.
