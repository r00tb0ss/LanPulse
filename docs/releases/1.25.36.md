# LanPulse 1.25.36

## Look-it-up links: Censys and Whois fixed
In an attacker's panel, the **Censys** link pointed at Censys's old search site, which has been retired, and the **Whois** link went to a page that often failed. Censys now opens its current platform, and Whois opens the Hurricane Electric BGP Toolkit page for the address (its Whois tab is selected). The other links are unchanged.

## Upgrade
Settings > Update > Check for updates. No `install.sh --upgrade` needed.
