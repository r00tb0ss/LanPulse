# LanPulse 1.25.4

## Network tab
- Removed the Groups and Tree views. The picker is now Topology (default), Rings, Tiles and Table.
- Topology: UniFi access points and switches now show the access point and switch icons.
- Topology: clicking a device now opens only the small inspector. The full device page opens from its "Open device" button.
- Topology: UniFi devices use their UniFi name, and the online/offline state UniFi reports, so a switch that doesn't answer LanPulse's scan no longer shows as offline.

## Upgrade
Settings > Update > Check for updates. No `install.sh --upgrade` needed.
