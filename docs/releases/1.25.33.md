# LanPulse 1.25.33

## Setup guide updated
The first-run guide (also under Settings > Setup guide) has a new optional step, **Block attackers and map your gear**, covering one-tap blocking on UniFi with the correct firewall policy (destination zone **Internal**) and reading other routers and switches over SNMP/LLDP. The honeypot step now notes that internet hits only arrive if you port-forward the decoy ports.

## Docs
The README and project page now describe SNMP/LLDP topology, real per-link traffic, the UniFi block policy and the "blocked, still connecting" warning, and the stale "SNMP isn't built yet" line is gone. New intro text on the project page and README.

## Upgrade
Settings > Update > Check for updates. No `install.sh --upgrade` needed.
