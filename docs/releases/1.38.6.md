# 1.38.6

Accuracy pass on the red-team exploitability score.

- Plain HTTP on port 80 no longer adds points, so an ordinary web server scores 0 instead of 10.
- A vulnerability match on a distro package, which may already be patched by a backport, now adds far fewer points than a confirmed-version match (8 instead of 30 for an actively exploited flaw), so it no longer rates a device "high".

The score is a planning aid, not a measurement.
