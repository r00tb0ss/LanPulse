# 1.29.1

## Fixes

- A device with no open ports (a Windows 10 or 11 PC behind its firewall, for example) no longer gets a made-up OS such as "Windows XP SP3". nmap can only fingerprint from an answering port, so with none LanPulse now shows no OS guess instead of a wrong one, and the old-Windows warning and CVEs go away. Run a scan on the device again to clear an old guess.
- Devices with Windows' default computer name (DESKTOP-XXXXXXX or LAPTOP-XXXXXXX) are now shown as "Windows 10 or 11 (guessed from its default computer name)" when nothing better is known. It is labelled a guess, carries no confidence, and is not used to match vulnerabilities.
