
## Metasploit script
The exported Metasploit resource script put each device's name on a comment line. A name containing a line break could end that comment and start a command of its own. Names are now flattened to one line.

## AI analyst
The "stays on your network" label for the AI server was decided by looking for text like `192.168.` or `localhost` anywhere in the address, so an address such as `https://192.168.example.com` was wrongly marked as local. It now checks the real host. The Anthropic default model name is also updated.

## Upgrade
