# LanPulse 1.25.26

## Honeypot: more captured on every port
- **Telnet:** real telnet clients and bots send option-negotiation bytes before the username, which showed up as junk in the login name. Those are now stripped. Up to three logins per connection are recorded (each as its own hit) instead of only the first.
- **FTP:** up to three USER/PASS attempts per connection are recorded; if a client never logs in, the commands it sent are noted.
- **HTTP:** records the request, the User-Agent and Host, Basic-Auth logins, and **form logins sent by POST** (username/password fields), not just Basic-Auth.
- **RDP:** records the login name a client puts in its connection request, when it sends one.
- **MySQL:** records the login name from the client's handshake.
- **SMB:** says whether the client opened with an SMBv1 or SMBv2/3 negotiation and lists the dialects it offered.
- The hit list now shows these details next to the login, not only when there was no login.

Not changed: SSH still records the client's version string only. Capturing SSH passwords needs a full SSH server library, which LanPulse doesn't ship.

Includes 1.25.25 (see every vulnerability on every host).

## Upgrade
Settings > Update > Check for updates. No `install.sh --upgrade` needed. Restart is handled by the updater.
