
## Daily summary
If the daily summary time was saved in an unexpected form (for example `8` instead of `08:00`), the background task that sends the summary stopped for good until the next restart. It now skips the bad value and keeps running.

## Threat ingest
The ingest address for honeypots and scripts accepted any request, with or without a key, if the ingest key had been cleared. With no key set it now accepts nothing.

## Upgrade
Settings > Update, or `git pull origin main && sudo ./install.sh`.
