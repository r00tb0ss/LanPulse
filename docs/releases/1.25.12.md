# LanPulse 1.25.12

## Honeypot settings
- **Ports:** change the port of any decoy (for example Telnet on 2323), not just turn it on or off.
- **Banners:** set what scanners see: the SSH banner, Telnet greeting, FTP banner, and the web server name and page title.
- **Slow scanners down:** optional delay per reply (a small tarpit).
- **Keep hits for:** 1 to 365 days (was fixed at 90).
- **Flood limit:** choose how many hits per address are logged within how many minutes.
- **Alerts:** switch off alerts for hits from the internet (hits from your own network always alert).
- **Never log these addresses:** an ignore list of IPs or ranges, such as a monitoring box.
- Found under Honeypot > Settings > Customize how the decoys look and behave. Includes 1.25.11 (honeypot details in the IP panel).

## Upgrade
Settings > Update > Check for updates. No `install.sh --upgrade` needed.
