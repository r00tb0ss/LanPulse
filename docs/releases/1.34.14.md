# LanPulse 1.34.14

## Security verification
- Adds regression coverage for dashboard password changes: previously issued session cookies are rejected after the signing secret rotates.
- Verifies the replacement password works and a newly issued session remains valid after the authentication store is reloaded.
- Documents the existing session-invalidation behavior in the project roadmap.

## Scope
- No runtime authentication behavior, API, settings, stored data format, or user data changes.
- This release adds automated protection against regressions in existing password-change security behavior.
