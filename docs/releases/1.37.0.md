# LanPulse 1.37.0

## Reports for every tab
- A new **Reports** button in the top bar (and a **Report** button on each tab) opens a professional, print-ready report. The current tab's report is listed first.
- **Executive security report** with the score, what needs attention and a summary of every tab.
- Detailed reports for **Network and devices, Threats, DNS, Vulnerabilities, Services and Red Team**.
- Five **Honeypot** reports: attacks, captured sessions with attack timelines, attacker profiles, campaigns and shared evidence, and malware samples with static analysis, score evidence and YARA matches. A sensors report is included too.
- Reports open as a page with a Print button and can be saved as PDF from the print dialog. When the optional `reportlab` package is installed, each report can also be downloaded as a PDF.
- Reports use only data LanPulse already holds. Nothing is scanned, captured files are never run, and indicators are shown defanged.
- The installer adds `reportlab` when it can. Without it, everything else works as before.
