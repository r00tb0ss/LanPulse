# LanPulse 1.39.7

## Honeypot malware intelligence
- Adds MalwareBazaar reputation lookups to captured malware sample details using the sample's SHA-256 hash.
- Reuses the existing abuse.ch Auth-Key configured under Settings → DNS; no separate MalwareBazaar key is required.
- Looks up hashes only. Captured malware files are never uploaded to MalwareBazaar.
- Caches successful results and backs off repeated lookup errors to avoid unnecessary API requests.
- Displays available MalwareBazaar family/signature, tags, and a direct hash permalink when returned by the service.

## Reliability
- Preserves valid punctuation in abuse.ch Auth-Key values instead of stripping characters that are part of the key.
- Adds regression coverage for exact Auth-Key transmission, hash-only lookup behavior, settings migration, and MalwareBazaar result handling.
