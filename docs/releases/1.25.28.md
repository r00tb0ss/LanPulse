# LanPulse 1.25.28

## Topology without UniFi: SNMP and LLDP
If your router or switches aren't UniFi, the Topology map can now learn the real wiring from them. In **Settings > UniFi**, add the addresses of your routers or switches and a read-only SNMP v2c community. LanPulse then reads, read-only:

- **LLDP neighbours** - which device is plugged into which port, so switches and access points are placed under the right parent.
- **The switch's MAC table** - which wired device was learned on which port.

Devices placed this way show "via SNMP" under *Connected to*, and a status chip appears in the Topology toolbar. UniFi data still wins where you have both, and anything you set by hand always wins.

Notes: only private LAN addresses are accepted, nothing is ever written to a device, and no extra package is needed. SNMP v2c sends the community in clear text, so use a read-only community. SNMP v3 is not supported yet. It has been tested against a simulated agent but **not yet against real switches**, so please report what you see. Polling happens about every two minutes.

## Upgrade
Settings > Update > Check for updates. No `install.sh --upgrade` needed.
