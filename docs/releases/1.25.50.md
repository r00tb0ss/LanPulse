
## Attack alerts from background intake
When an attack was reported through a background task (a honeypot sensor or the ingest API), the live update and the alert ("attack reached a device", "attack burst") were skipped. Both are now sent.

## Fewer rare errors
The threat page and an attacker's detail view read the device list while it was changing, and the detail view could fail on an event stamped slightly in the future. Both are fixed, and the lookup cache for attacker details no longer grows without limit.

## Upgrade
Settings > Update, or `git pull origin main && sudo ./install.sh`.
