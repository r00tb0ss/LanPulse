Findings carry a confidence level. confirmed means a thorough scan actively tested the flaw on the device (e.g. EternalBlue over SMB) — not a guess. Everything else is matched by version number: Linux distributions often patch a flaw without changing the version, so results marked may be patched could already be fixed by your OS updates, and patch level unknown covers a Windows version whose updates a scan can't see. Turn on Thorough scan on a device to run the active checks. Data: NVD (NIST), CISA's Known Exploited Vulnerabilities list, Metasploit module metadata and Exploit-DB. This product uses the NVD API but is not endorsed or certified by the NVD.

This is a low-interaction honeypot: the decoys log connections and the logins attackers try, but never grant access or run anything.
